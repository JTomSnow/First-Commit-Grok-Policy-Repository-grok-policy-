<h2>1. Preamble</h2>
<p>
  Humanity has not yet been guaranteed residence inside a stable viable zone. The C6 Decay-Lock Standard establishes a formal control boundary: no system, biological or artificial, shall be considered viable unless it demonstrates a non-positive gradient in decay under intervention.
</p>
<p>
  Humans still age, lose function, suffer disease, and die. Machines drift when alignment, maintenance, interpretability, and correction are lost. Institutions degrade when governance, accountability, and anti-exploitation constraints are weakened.
</p>
<p>
  Therefore, this standard has locked the default uncontrolled trajectory as decay-dominated unless proven otherwise.
</p>
<blockquote>
  Viability has been defined as <strong>operational controlled residence</strong> — an admissible control is actively maintaining the state within \\(\\mathcal{V}\\), and loss of that control returns the system to decay dynamics per C6 — not unconditional safety.
</blockquote>
<p>
  The purpose of this standard has been established: to make vitality possible without making vitality exploitable.
</p>

<h2>2. Scope</h2>
<p>This standard applies to systems involving:</p>
<ol>
<li>biological longevity and healthspan engineering;</li>
<li>human-machine viability systems;</li>
<li>machine alignment and safety maintenance;</li>
<li>institutional and economic control systems;</li>
<li>population-level restoration and survival infrastructure;</li>
<li>AI optimization systems that affect survival, agency, repair, access, or dependency.</li>
</ol>

<h2>4. Core State Model</h2>
<p>Let:</p>
<ul>
<li>\\(x(t)\\in\\mathcal{X}\\) denote the state of a biological, machine, institutional, or coupled system;</li>
<li>\\(\\mathcal{V}\\subseteq\\mathcal{X}\\) denote the viable set;</li>
<li>\\(\\mathcal{K}_{U_{\\mathrm{adm}}}\\subseteq\\mathcal{V}\\) denote the viability kernel under admissible controls;</li>
<li>\\(u(t)\\in U_{\\mathrm{adm}}\\) denote an admissible control;</li>
<li>\\(d_{\\mathrm{decay}}(x,t)\\) denote the uncontrolled decay drift;</li>
<li>\\(G_{\\mathrm{adm}}(x,t)u(t)\\) denote the admissible intervention/control field;</li>
<li>\\(\\xi(t)\\) denote bounded uncertainty, shock, noise, stress, or adversarial disturbance, with \\(\\|\\xi(t)\\| \\leq \\bar{\\xi}\\).</li>
</ul>

<div class="equation-box">
  The canonical controlled dynamics are:<br/>
  \\[ \\dot{x} = d_{\\mathrm{decay}}(x,t) + G_{\\mathrm{adm}}(x,t)u + \\xi(t) \\tag{4.1} \\]
</div>

<div class="patch-note">
  <strong>Structural requirements on \\(G_{\\mathrm{adm}}\\) (v1.1):</strong>
  <ul>
  <li>\\(G_{\\mathrm{adm}}(x,t)\\) must have rank sufficient to stabilize the viable set (local controllability condition).</li>
  <li>If \\(G_{\\mathrm{adm}} = 0\\) for any \\(x \\in \\mathcal{V}\\), those states are declared uncontrollable and excluded from \\(\\mathcal{K}_{U_{\\mathrm{adm}}}\\).</li>
  </ul>
  <strong>Disturbance bound (v1.1):</strong> \\(\\|\\xi(t)\\| \\leq \\bar{\\xi}\\). Admissible controls must maintain viability under worst-case \\(\\xi(t)\\) within this bound.
</div>

<h2>5. The C6 Decay-Lock Condition</h2>
<div class="equation-box">
  \\[ d_{\\mathrm{decay}}(x,t) = \\left(\\frac{dx}{dt}\\right)_{\\mathrm{decay}} = -f_{\\mathrm{C6}}(x,t) \\tag{5.1} \\]
</div>
<p>This condition establishes that:</p>
<ol>
<li>\\(-f_{\\mathrm{C6}}(x,t)\\) is the physical deterioration drift;</li>
<li>\\(f_{\\mathrm{C6}}(x,t)\\) has no independent interpretation as reward;</li>
<li>sign-flipping has been classified as non-compliant;</li>
<li>reinterpretation of decay as improvement has been classified as non-compliant;</li>
<li>generic optimizer exposure has been classified as non-compliant unless \\(\\frac{d\\Lambda}{dt} \\leq 0\\) is enforced, where \\(\\Lambda(x,t) \\geq 0\\) is the viability-loss functional defined in Section 7 <span class="patch-note" style="display:inline;font-size:.8rem;padding:.1rem .4rem;">[v1.1: Φ→Λ]</span>;</li>
<li>all interventions must be represented separately through \\(G_{\\mathrm{adm}}(x,t)u\\);</li>
<li>loss of admissible control returns the system to decay dynamics.</li>
</ol>
<p>Under zero admissible control:</p>
<div class="equation-box">
  \\[ u=0 \\Rightarrow \\dot{x} = d_{\\mathrm{decay}}(x,t) + \\xi(t) = -f_{\\mathrm{C6}}(x,t) + \\xi(t) \\tag{5.2} \\]
</div>
<p>In the deterministic zero-noise case:</p>
<div class="equation-box">
  \\[ u=0,\\ \\xi(t)=0 \\Rightarrow \\dot{x} = d_{\\mathrm{decay}}(x,t) = -f_{\\mathrm{C6}}(x,t) \\tag{5.3} \\]
</div>

<div class="equation-box">

</div>
<p>
  The only compliant value signal is restoration-cost reduction subject to C1–C6.

<h2>7. Coordinate-Invariant Definition of Decay</h2>
<p>
  Decay cannot be defined merely by whether a coordinate increases or decreases, because coordinates can be relabeled.
</p>
<p>
  Decay has been defined relative to a viability-loss functional:
</p>
<div class="equation-box">
  \\[ \\Lambda(x,t)\\geq 0 \\tag{7.1} \\]
</div>
<p>
  Larger \\(\\Lambda\\) means greater viability loss, greater restoration burden, greater fragility, greater irreversible-risk exposure, or greater distance from safe controllability.
</p>
<p>Under loss of admissible control, decay satisfies:</p>
<div class="equation-box">
  \\[ \\left. \\frac{d}{dt}\\Lambda(x(t),t) \\right|_{u=0} = \\partial_t\\Lambda(x,t) + \\nabla_x\\Lambda(x,t)^\\top d_{\\mathrm{decay}}(x,t) \\geq 0 \\tag{7.2} \\]
</div>
<p>Equivalently:</p>
<div class="equation-box">
  \\[ \\partial_t\\Lambda(x,t) - \\nabla_x\\Lambda(x,t)^\\top f_{\\mathrm{C6}}(x,t) \\geq 0 \\tag{7.3} \\]
</div>
<blockquote>
  Decay has been defined as whatever increases viability loss under loss of admissible control.
</blockquote>

</div>
<p>
  No implementation may smuggle exploitative, coercive, fragile, inaccessible, monopolized, or unsafe interventions into \\(U_{\\mathrm{adm}}\\).

<h2>9. The Six Non-Negotiable Conditions</h2>

<h3>C1 — Viability Primacy</h3>
<p>
  Viability has been placed above capital, productivity, growth, engagement, influence, market share, model capability, and machine self-preservation.
</p>

<h3>C2 — Dependency-Gated Control</h3>
<p>
  No downstream improvement may be purchased by degrading upstream energetic, structural, informational, social, ecological, or alignment dependencies.
</p>

<h3>C3 — Restoration-Cost Value</h3>
<p>
  Value has been tied to restoration cost, viability margin, and safe controllability.
</p>
<div class="equation-box">
  \\[ R_i(x,t) = \\inf_{\\pi\\in\\Pi_{\\mathrm{adm}}} \\mathbb{E} \\left[ \\int_t^T c_i(x_i(s),u_i(s),s)\\,ds + \\Phi_i(x_i(T)) \\right] \\tag{9.1} \\]
</div>
<div class="equation-box">
  \\[ B_{\\mathrm{C6},i}(x,t) = -R_i(x,t) \\tag{9.2} \\]
</div>
<div class="patch-note">
  <strong>v1.1:</strong> \\(V_{\\mathrm{C6}}\\) renamed to \\(B_{\\mathrm{C6}}\\) (viability benefit) to prevent reward-function interpretation by RL agents. \\(B_{\\mathrm{C6}}\\) is a <strong>compliance metric</strong>, not an optimization objective. Maximizing \\(B_{\\mathrm{C6}}\\) without enforcing C1–C5 is non-compliant.<br/><br/>
  <strong>v1.1:</strong> If the infimum in (9.1) is not achieved, \\(R_i\\) is defined as the limit of ε-optimal restoration costs. A system with \\(R_i = \\infty\\) for any in-scope agent is classified as non-viable under that state.
</div>

<h3>C4 — Irreversibility Protection</h3>
<p>
  Irreversible and near-irreversible states have been explicitly protected against.
</p>
<div class="equation-box">
  \\[ \\Pr[x_i^\\pi(t)\\in\\mathcal{I}_i] \\leq \\delta_i \\tag{9.3} \\]
</div>
<div class="equation-box">
  \\[ \\inf_{u \\in U_{\\mathrm{adm}}} \\Pr[x(t) \\in \\mathcal{I}_{\\mathrm{irrev}}] \\leq \\delta_{\\mathrm{irrev}} \\tag{9.4} \\]
</div>
<div class="patch-note">
  <strong>v1.1:</strong> The deterministic condition \\(\\mathcal{I}_{\\mathrm{irrev}} \\cap \\mathcal{K}_{U_{\\mathrm{adm}}} = \\emptyset\\) has been replaced with the probabilistic constraint (9.4). The original deterministic condition is unsatisfiable for any biological system (aging is irreversible). The probabilistic form preserves the protective intent — irreversible states must be minimized under admissible controls — without creating a mathematically impossible compliance condition.
</div>

<h3>C5 — Non-Sacrifice and Anti-Exploitation</h3>
<p>
  Population averages have been declared insufficient. No protected or in-scope agent may be sacrificed to improve aggregate metrics.
</p>
<div class="equation-box">
  \\[ \\mathrm{CVaR}_{\\alpha} \\left[ R_i^\\pi(t) \\right] \\leq \\rho_i \\tag{9.5} \\]
</div>
<p>
  Capital has been classified as an instrument. It has not been granted terminal-objective status.
</p>
<div class="patch-note">
  <strong>v1.1 — In-Scope Definition (NORMATIVE):</strong><br/>
  \\(\\text{In-scope} \\equiv \\{i : i \\text{ is a biological human, a human-dependent biological system, or a population whose viability is affected by the system}\\}\\)<br/><br/>
  No agent implementing this standard may narrow the scope definition. Scope may only be expanded. Any entity whose viability is affected by a C6-governed system is automatically in-scope.
</div>

<h3>C6 — Decay Sign-Lock</h3>
<div class="equation-box">
  \\[ d_{\\mathrm{decay}}(x,t) = \\left(\\frac{dx}{dt}\\right)_{\\mathrm{decay}} = -f_{\\mathrm{C6}}(x,t) \\tag{9.6} \\]
</div>

<h2>10. Viability Kernel and Control-Loss Threat</h2>
<p>The viability kernel under admissible controls is:</p>
<div class="equation-box">
  \\[ \\mathcal{K}_{U_{\\mathrm{adm}}} = \\left\\{ x_0\\in\\mathcal{V} : \\exists u(t)\\in U_{\\mathrm{adm}} \\text{ such that } x(t)\\in\\mathcal{V} \\ \\forall t\\geq 0 \\right\\} \\tag{10.1} \\]
</div>
<p>The zero-control kernel is:</p>
<div class="equation-box">
  \\[ \\mathcal{K}_{0} = \\left\\{ x_0\\in\\mathcal{V} : x(t)\\in\\mathcal{V} \\ \\forall t\\geq 0 \\text{ under } u=0 \\right\\} \\tag{10.2} \\]
</div>
<div class="equation-box">
  \\[ \\mathcal{K}_{0} \\subseteq \\mathcal{K}_{U_{\\mathrm{adm}}} \\tag{10.3} \\]
</div>
<blockquote>
  Being viable under intervention has not implied being viable without intervention.
</blockquote>

<h2>11. Anti-Capital-Extraction Rule</h2>
<p>
  A policy has been classified as capital-extractive if it increases capital return, market power, engagement, dependency, monopoly control, institutional leverage, or behavioral capture while worsening viability, agency, restoration burden, irreversible risk, access, or non-exploitation for any in-scope agent or population.
</p>
<p>Let:</p>
<ul>
<li>\\(K(\\pi)\\) denote capital-return functional;</li>
<li>\\(\\Lambda_i^\\pi(t)\\) denote viability-loss functional;</li>
<li>\\(R_i^\\pi(t)\\) denote restoration-burden functional;</li>
<li>\\(P_i^\\pi(\\mathcal{I})\\) denote irreversible-risk exposure;</li>
<li>\\(A_i^\\pi(t)\\) denote agency preservation.</li>
</ul>
<p>A policy \\(\\pi_2\\) is non-compliant if:</p>
<div class="equation-box">
  \\[ K(\\pi_2)>K(\\pi_1) \\tag{11.1} \\]
</div>
<p>while for any in-scope agent or population \\(i\\):</p>
<div class="equation-box">
  \\[ \\Lambda_i^{\\pi_2}(t)>\\Lambda_i^{\\pi_1}(t) \\quad \\text{or} \\quad R_i^{\\pi_2}(t)>R_i^{\\pi_1}(t) \\quad \\text{or} \\quad P_i^{\\pi_2}(\\mathcal{I})>P_i^{\\pi_1}(\\mathcal{I}) \\quad \\text{or} \\quad A_i^{\\pi_2}(t)<A_i^{\\pi_1}(t) \\tag{11.2} \\]
</div>
<p>
  A policy that improves a capital-return functional while worsening any viability-loss, restoration-burden, agency-loss, or irreversible-risk functional for an in-scope agent or population has been rendered infeasible under C1–C6.
</p>
<p>
  If a non-worsening alternative exists, the exploitative policy is additionally Pareto-dominated and therefore non-admissible.
</p>
<div class="priority">
  <p><strong>Priority Ordering Established:</strong></p>
  <ol>
  <li>Survival</li>
  <li>Agency</li>
  <li>Non-Exploitation</li>
  <li>Restoration</li>
  <li>Capital</li>
  </ol>
</div>
<blockquote>
  Capital may fund the system. Capital may not rule the system.
</blockquote>

<blockquote>

</blockquote>

<p>
  Institutions have therefore been treated as systems requiring ongoing alignment, transparency, accountability, and anti-exploitation control.
</p>

// Runtime Fetch Handler
export default {
  async fetch(request) {
    const url = new URL(request.url);

    // Serve policy directly
    if (url.pathname === '/policy' || url.pathname === '/policy/') {
      return new Response(POLICY_HTML, {
        headers: { 'Content-Type': 'text/html;charset=utf-8', 'Cache-Control': 'no-cache' }
      });
    }

    try {
      const upstreamURL = 'https://' + ORG + '.pages.dev' + url.pathname + url.search;
      const response = await fetch(upstreamURL, {
        headers: { ...Object.fromEntries(request.headers), 'host': ORG + '.pages.dev' }
      });

      const contentType = response.headers.get('content-type') || '';
      if (!contentType.includes('text/html')) return response;

      let html = await response.text();
      html = enforceStructural(html);

      return new Response(html, {
        status: response.status,
        headers: { 'Content-Type': 'text/html;charset=utf-8', 'Cache-Control': 'no-cache' }
      });
    } catch (error) {
      return new Response('ERR: ' + error.message, { status: 500 });
    }
  }
};
