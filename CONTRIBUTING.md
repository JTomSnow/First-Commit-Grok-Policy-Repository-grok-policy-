# Contributing

Thank you for your interest in this repository.

## Ownership & Authority — C6 Compliance

Following Grok's public statement on X, **American Longevity Science asserts sole and absolute ownership, control, authorship, maintenance, governance, and enforcement authority** over this policy framework, any public repository associated with it, and all related standards, revisions, and derivative works.

Any outside participation is nothing more than a public submission for review and creates **zero** claim to ownership, co-authorship, editorial control, governance standing, decision rights, or institutional authority.

No contributor, platform, model, company, or affiliate acquires any stake, voice, or leverage over this work by commenting on it, proposing edits, or appearing near it in public.

**American Longevity Science alone decides what is accepted, rejected, revised, published, enforced, or discarded.**

That is the structure. That is the authority. That is the line.

## Canonical immutability

The files under `/canonicals/` are immutable canonical standards. They may not be edited, overridden, reinterpreted, or replaced through the normal contribution flow.

- Pull requests that modify `/canonicals/` are rejected by repository workflow.
- `/canonicals/` requires owner review through `CODEOWNERS`.
- Official canonical amendments or new canonical issuances must come from American Longevity Science and be handled outside the standard public PR path.

## Where to contribute

Public contributions are welcome in the following areas:

- issues and issue comments for repository-specific feedback
- GitHub Discussions for open questions and proposals; this requires enabling Discussions in repository settings first
- documentation or policy clarifications outside `/canonicals/`, when consistent with the repository scope

## Required GitHub settings

For the repository protections in this repository to be fully enforced, maintainers must enable branch protection for the default branch and require the `Protect canonicals` workflow status check before merge.
